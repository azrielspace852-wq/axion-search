AXIONSearch

Changelog

All notable changes to AXION Search. Versions follow semantic versioning.

[4.2.0] — 2026-10-19 current

  • Separated repository layout: all static UI and Pages Functions live under pages/; the API Worker and engine live under workers/.
  • Cloudflare-only production: removed Cloudflare Tunnel and VPN/proxy configurations from active deployment; Worker and Pages connect through AXION_SEARCH_API.
  • Google AI Studio: live SSE responses; only gemma-4-31b-it and gemma-4-26b-a4b-it are used, with automatic round-robin model rotation and optional key rotation. Model selection was removed from the UI and ignored in client input.
  • IndexedDB history: search history moved out of localStorage with one-time migration and JSON export/import compatibility.
  • Search UX: All is the default search vertical; All and AI Mode are the first two tabs. Tab styling and keyboard focus states were refined.
  • CPU/subrequest efficiency: set the Worker and Pages Function CPU limit to 10 ms; bounded HTML reads, lighter parsing, provider fan-out control, and reuse of results for AI summaries.
  • SDK: adds `summaryStream()` and `chatStream()` to consume live server-sent events while leaving model selection to the Worker.

[4.1.0] — 2026-10-19 previous

  • Cloudflare architecture: static UI on Pages and a Fetch-based API on Workers, connected through a Service binding.
  • Domain split: website at search.xxn.cc.cd; API at api.search.axn.cc.cd.
  • SDK and route compatibility: separate API/site origins and support for legacy API routes.

[3.0.0] — 2026-10-10 legacy

  • Legacy Node hosting (historical): GitHub Actions self-chaining workflow and Cloudflare Tunnel. This is historical only; production now uses Pages + Workers.
  • Multi-provider rotation: Google → Bing → DuckDuckGo → Mojeek (web); Bing/DDG (images); Bing/YouTube (videos); Google News/Bing (news); iTunes (audio); plus Apps & Shop verticals.
  • Result merging: up to 3 providers queried per request, merged & de-duplicated for richer results.
  • AI: 3 rotating API keys, selectable legacy models (replaced by fixed Gemma 4 rotation in v4.2), on/off toggle, grounded anti-hallucination prompt with citations.
  • AXION priority: queries mentioning AXION surface *.axn.cc.cd results first; dedicated AXION tab.
  • Multi-language: 11 languages (UI + AI reply), default English.
  • Pages: separate home & search pages, Settings, Privacy, SafeSearch, Docs, Changelog, Roadmap, Blueprint, Bible, SDK.
  • Data: preferences in localStorage/cookies and search history in IndexedDB; one-click export/import JSON for device migration.
  • Themes: dark & light. SafeSearch toggle. OpenSearch + sitemap.xml + robots.txt.
  • SDK: JS SDK + browser default-search-engine integration.

[2.0.0] — earlier

  • Bing-only scraping (web/images/videos), single Gemini key, single-page UI, Indonesian default.

[1.0.0] — initial

  • Minimal Express + Bing web search prototype.
