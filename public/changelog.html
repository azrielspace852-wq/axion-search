Changelog

v5.0 — October 2026 (major migration)

  • Removed Cloudflare Tunnel, GitHub Actions, VPNX proxy, and the Express scraping server.
  • Migrated all search to third-party APIs: Brave, SerpDive (Krill), Tavily — unified abstraction.
  • New hosting: Cloudflare Pages (frontend) + Cloudflare Workers (backend), connected via Service Bindings.
  • Domains: search.axn.cc.cd (Pages) / api.search.axn.cc.cd (Worker).
  • CPU budget ≤10ms; subrequest & connection limits enforced via concurrency pooling + aggressive caching.
  • Multi-tier caching: edge (Cache API + KV) + client (IndexedDB).
  • AI: Google AI Studio, 3-key round-robin, models gemma-4-31b-it / gemma-4-26b-a4b-it auto-rotated; user model selection removed.
  • Secrets moved to Cloudflare Dashboard environment variables.
  • Client storage migrated from localStorage to IndexedDB.
  • Full UI/UX overhaul; AI & All tabs moved to the far left; default tab on submit = All.
  • i18n expanded to 10 languages with instant DOM switching + Arabic RTL.
  • Added Donate link, "Buy me a coffee" popup (every 10 days), "Join AXION Labs as a Creator" popup (every 15 days).
  • Mandatory consent/onboarding screen; decline blocks the current session only.
  • Rebuilt SDK (Node.js + browser + AI agents) with documentation.
  • License changed to CC BY-NC-ND 4.0.

v4.x — earlier

Express + scraping (Google/Bing/DDG/Mojeek/Yahoo), GitHub Actions 24/7 self-chaining, Cloudflare Tunnel, VPNX proxy.
