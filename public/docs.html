AXIONSearch

Documentation v4.0

AXION Search — self-hostable, privacy-first meta search engine with grounded AI summaries and AI Chat Mode, running 24/7 on GitHub Actions behind a Cloudflare Tunnel and VPNX proxy.

Quick start (self-host)

  1. Fork / push this repository to GitHub.
  2. Create a Cloudflare Tunnel named axion-search (hostname → http://localhost:3000). Download cert.pem and <UUID>.json.
  3. Add GitHub Secrets: CLOUDFLARED_CERT_PEM, TUNNEL_CREDENTIALS_JSON, TUNNEL_UUID, GH_PAT, AI_KEY_1/2/3.
  4. Anti-block (wajib): tambah secret credential VPN (VPN_USER, VPN_PASSWORD, VPN_PROVIDER, opsional VPNX_IMAGE) dan opsional BRAVE_API_KEY. Workflow akan otomatis menjalankan container VPNX dan semua request pencarian keluar lewat proxy http://localhost:8888.
  5. Enable workflow. Aksi schedule (setiap 30 menit) akan spin-up server. Self-chain memastikan 24/7.

Public API (CORS-enabled)

Semua endpoint bisa dipanggil langsung dari browser (termasuk dari search engine bawaan browser) maupun dari server lain.

Search

GET /api/v1/search?q=kucing&type=web&safe=1&lang=id
# type: web | images | videos | news | audio | apps | shop | all

Direct search URL (untuk browser / OpenSearch)

https://axion-search.axn.cc.cd/search?q={searchTerms}
https://axion-search.axn.cc.cd/s/{searchTerms}   # shortcut

AI summary

GET /api/summary?q=...&model=gemini-2.5-flash&lang=id

AI Chat Mode (grounded, auto-search)

POST /api/v1/chat
Content-Type: application/json
{ "messages": [{"role":"user","content":"apa itu axion?"}], "lang":"id" }

Search tool untuk layanan AI eksternal (OpenAI-compatible)

GET /api/v1/tool/search?q=berita+terbaru
# → { query, results: [{title, url, snippet, source}, ...] }

Daftarkan sebagai function tool di AI apa pun (OpenAI, Gemini, dll) dengan spesifikasi:

{ "type":"function", "function":{ "name":"axion_web_search",
  "description":"Search the web via AXION Search",
  "parameters":{ "type":"object", "properties":{ "query":{"type":"string"} }, "required":["query"] } } }

Anti-block strategy (mengapa tidak diblokir)

  1. VPNX Docker proxy — semua request keluar lewat IP VPN, bukan IP GitHub Actions.
  2. Rotasi 7+ provider — DDG, Bing, Google (basic+regular), Yahoo, Mojeek, Brave. Satu diblokir, yang lain jalan.
  3. Rotasi User-Agent — 5 UA berbeda acak tiap request.
  4. Timeout 100 detik — retry multi-provider punya waktu cukup.
  5. Error selalu tercatat ke stderr — mudah diaudit.

Tab & Fitur UI

  • Web / Images / Videos / News / Audio / Apps / Shop — hasil per-kategori.
  • AI Mode — chat dengan AI tentang pencarian; klik kartu ringkasan AI otomatis masuk ke sini.
  • Semua (All) — gabungan semua kategori dalam satu halaman.
  • Sidebar — hamburger atau swipe kanan→kiri; berisi navigasi + riwayat pencarian.
  • Personalisasi — riwayat & tren di beranda, tersimpan di localStorage.
