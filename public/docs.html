AXIONSearch

Documentation v3.0

AXION Search — self-hostable, privacy-first meta search engine with grounded AI summaries, running 24/7 on GitHub Actions behind a Cloudflare Tunnel.

Quick start (self-host)

  1. Fork / push this repository to GitHub.
  2. Create a Cloudflare Tunnel named axion-search with hostname axion-search.axn.cc.cd → http://localhost:3000. Download cert.pem and <UUID>.json.
  3. Add GitHub Secrets (Settings → Secrets and variables → Actions):
    • CLOUDFLARED_CERT_PEM — full content of cert.pem
    • TUNNEL_CREDENTIALS_JSON — full content of <UUID>.json
    • TUNNEL_UUID — the tunnel UUID
    • AI_KEY_1, AI_KEY_2, AI_KEY_3 — 3 Google AI Studio keys (rotated)
    • AI_MODEL_DEFAULT — e.g. gemini-3.5-flash-lite
    • GH_PAT — Personal Access Token with repo + workflow scope (for self-chaining)
  4. Trigger the workflow once (Actions → axion-247 → Run workflow). It will self-chain forever. The 30-min cron is a safety net.

How 24/7 works (6h job limit)

Each GitHub Actions job is capped at 6 hours. AXION solves this with a self-chaining loop:

  1. Job starts, waits until the previous job's origin is down (health-check loop, max 50 min).
  2. Starts cloudflared tunnel run axion-search (supports multi-connector HA, so overlap is harmless) + node server.js.
  3. At minute 290 (4h50m), a background process dispatches the next job via GH API using GH_PAT.
  4. Job keeps serving until minute 345; timeout-minutes: 350 kills it at 5h50m — always under 6h.
  5. Next job, already started, takes over within seconds. A cron every 30 min restarts the chain if it ever breaks.

All output is suppressed (SILENT=1, >/dev/null 2>&1). Nothing is printed; no secret ever appears in logs.

Direct URL search

https://axion-search.axn.cc.cd/search?q=your+query returns the full results page (with AI summary). This is the URL format used when you set AXION as your browser's default search engine — see the SDK page.

Provider rotation

For each query type, AXION keeps an ordered list of providers. The starting index rotates every minute (load distribution). It tries up to 3 providers, merging and de-duplicating results for richness. If Google blocks, Bing answers; if Bing fails, DuckDuckGo answers — automatically. AXION-domain results (*.axn.cc.cd) are always prioritized to the top when the query mentions AXION.

AI: no hallucination

The AI prompt includes only the top search snippets as context, with explicit instructions: answer only from context, cite by number, and say "not found" when context is insufficient. Temperature is fixed at 0.1. Three API keys rotate round-robin; on 429/quota errors the next key is tried automatically. Model is user-selectable in Settings.
