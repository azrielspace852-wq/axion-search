Architecture (v5)

  • Frontend: Cloudflare Pages — search.axn.cc.cd (static assets + Pages Function).
  • Backend: Cloudflare Worker — api.search.axn.cc.cd (serverless API).
  • Service Binding: the Pages Function forwards /api/* to the Worker internally — no external HTTP overhead.
  • Search providers: Brave Search API, SerpDive (Krill), Tavily — unified abstraction layer. No scraping.
  • AI: Google AI Studio, 3 rotating keys, 2 auto-rotated models (gemma-4-31b-it, gemma-4-26b-a4b-it).
  • Caching: Tier 1 edge (Cache API + KV), Tier 2 client (IndexedDB).
  • Storage: IndexedDB (replaced localStorage).
