AXIONSearch

Roadmap

Where AXION Search is headed. Priorities shift based on usage and feedback.

v4.2 — Q4 2026 (next)

  • Pagination / "next page" with per-provider offset support.
  • Instant answers / knowledge panel (calculator, weather, definitions).
  • Search suggestions (autocomplete) dropdown.
  • Per-result "cached" and "similar" links.

v4.3 — Q1 2027

  • Conversational AI follow-up questions (chat mode) with grounded context.
  • Image & video preview lightbox.
  • Region filter (country-specific results).
  • Time filter (past hour / day / week / year).

v4.4 — Q2 2027

  • Custom provider API keys (Brave Search, SerpAPI) as optional backends.
  • Self-hostable Docker image + one-click deploy to Railway/Fly.
  • Browser extension (Chrome/Firefox) for AXION as default search.
  • AXION site search crawler (index *.axn.cc.cd directly, no third-party dependency).

Long-term (v5)

  • Federated AXION index — peer nodes share the AXION-domain index.
  • On-device LLM option for AI summary (WebGPU) — zero data leaves the browser.
  • Multi-modal search (image → web).
  • Translated search (query in one language, results in another).
Status of each item is tracked in the repository. Community contributions welcome — see the SDK to build on AXION.
