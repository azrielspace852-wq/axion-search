SafeSearch

SafeSearch filters explicit adult content from search results. It is enabled by default and can be toggled in Settings.

How it works

  • Queries are augmented with negative terms (-porn -xxx -nsfw) sent to the search APIs.
  • Brave Search API is called with safesearch=strict when enabled.
  • Returned results are filtered a second time on the edge against a blocklist of explicit domains and keywords.

No filter is perfect. If you find inappropriate content, please report it via the AXION Hub.
