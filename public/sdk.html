AXIONSearch

SDK & Integrations

Use AXION Search as your browser's default engine, embed it in your app, or call it from your AI agent. No API key required for public endpoints.

1. Set as default browser search engine

AXION ships an OpenSearch description. In Chrome/Edge/Firefox, visit the homepage once — the browser will offer "Add AXION Search". Or add manually with this search URL template:

https://axion-search.axn.cc.cd/search?q=%s

(works in Chromium browsers)

2. JavaScript SDK

Include the SDK and search from any webpage or AI agent frontend:

<script src="https://axion-search.axn.cc.cd/sdk/axion-search-sdk.js"></script>
<script>
  const axn = new AxionSDK({ base: 'https://axion-search.axn.cc.cd' });

  // Web search
  const res = await axn.search('neural networks', { type: 'web', safe: true, lang: 'en' });
  console.log(res.results);  // [{title, link, snippet, source}]

  // Grounded AI summary
  const sum = await axn.summary('what is axion?', { model: 'gemini-3.5-flash-lite', lang: 'en' });
  console.log(sum.summary);

  // Vertical: images, videos, news, audio, apps, shop, axion
  const imgs = await axn.search('cat', { type: 'images' });
</script>

Download: axion-search-sdk.js (UMD, zero dependencies, ~2KB).

3. cURL / any HTTP client

curl "https://axion-search.axn.cc.cd/api/search?q=hello&type=web&safe=1&lang=en"
curl "https://axion-search.axn.cc.cd/api/summary?q=hello&model=gemini-3.5-flash-lite&lang=en"
curl "https://axion-search.axn.cc.cd/health"

4. For AI agents (function calling)

Expose AXION as a tool to your LLM agent. Two functions:

functionparamsreturns
axion_searchquery, type (web/images/videos/news/audio/apps/shop/axion), safe, langup to 30 results with title/link/snippet
axion_summarizequery, model, langgrounded summary with citations

Because results are grounded and cited, agents using AXION avoid hallucinating sources — the AI summary itself is built from the same snippets your agent receives.

5. AXION ecosystem search

To search only AXION sites (*.axn.cc.cd), use type=axion or the dedicated AXION tab. AXION results are also auto-prioritized in web search when the query mentions AXION.

curl "https://axion-search.axn.cc.cd/api/search?q=neuralis&type=axion"

Rate limits

The public instance is shared — please be reasonable (burst of a few req/s is fine). For heavy use, self-host your own copy in under 5 minutes.
