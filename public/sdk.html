AXIONSearch

SDK & Integrations

Use AXION Search from a web page, application, command line, or AI agent. The public API is hosted on a separate Cloudflare Worker, while the website and SDK file are served by Cloudflare Pages.

1. Domains and architecture

Website / Pages: https://search.xxn.cc.cd

API / Worker: https://api.search.axn.cc.cd

Requests from the website use relative /api/* URLs. A Pages Function forwards them to the API Worker through the AXION_SEARCH_API service binding. SDK clients outside the website call the API domain directly.

2. Set as default browser search engine

AXION includes an OpenSearch description. Use the following search URL template when adding it manually:

https://search.xxn.cc.cd/search?q=%s

(browser support varies)

3. JavaScript SDK

The SDK has no runtime dependencies. The default API and website origins are configured automatically:

<script src="https://search.xxn.cc.cd/sdk/axion-search-sdk.js"></script>
<script>
  const axn = new AxionSDK();

  const web = await axn.search('neural networks', { type: 'web', safe: true, lang: 'en' });
  console.log(web.results);

  const summary = await axn.summary('what is AXION?', { lang: 'en' });
  console.log(summary.summary);

  const chat = await axn.chat([{ role: 'user', content: 'Explain neural networks' }], { lang: 'en' });
  console.log(chat.reply);

  const imageResults = await axn.search('cat', { type: 'images' });
  const toolResults = await axn.aiToolSearch('latest science news');
</script>

Download: axion-search-sdk.js.

Explicit configuration

const axn = new AxionSDK({
  apiBase: 'https://api.search.axn.cc.cd',
  siteBase: 'https://search.xxn.cc.cd',
  timeout: 45000
});

The older { base: 'https://…' } option remains supported for compatibility with SDK v4.0. For the new split-domain architecture, prefer apiBase and siteBase.

4. cURL / HTTP API

curl "https://api.search.axn.cc.cd/api/v1/search?q=hello&type=web&safe=1&lang=en"
curl "https://api.search.axn.cc.cd/api/summary?q=hello&model=gemini-2.5-flash&lang=en"
curl "https://api.search.axn.cc.cd/health"

5. API endpoints

MethodEndpointPurpose
GET/api/v1/searchSearch with selected vertical.
GET/api/v1/tool/searchCompact result format for AI function calling.
POST/api/v1/chatGrounded AI chat using fresh search context.
GET/api/searchLegacy-compatible search endpoint.
GET/api/summaryGrounded AI summary.
GET/healthWorker health/configuration status.

Supported search types: web, images, videos, news, audio, apps, shop, axion, and all.

6. AI tool / function calling

The SDK exposes a function-call schema:

const tool = axn.openaiToolSpec();
const results = await axn.aiToolSearch('latest science news');

Tool endpoint: GET https://api.search.axn.cc.cd/api/v1/tool/search?q=.... It returns results as { query, results: [{ title, url, snippet, source }] }.

7. AXION ecosystem search

To search AXION ecosystem sites, use the axion type:

const axionSites = await axn.search('Neuralis', { type: 'axion', lang: 'id' });
// Direct API:
// https://api.search.axn.cc.cd/api/v1/search?q=Neuralis&type=axion

8. Privacy and operational notes

Language, theme, and search history settings remain in the browser's local storage. The API does not require a client API key for public endpoints. Requests are processed by Cloudflare Workers; do not submit private data that should not be sent to third-party search providers or the configured AI provider.
