AXIONSearch

AXION Search SDK

Zero-dependency, UMD. Works in Node.js, vanilla JS (browser), and as a tool for external AI agents.

Download axion-search-sdk.js

Browser (vanilla JS)

<script src="/sdk/axion-search-sdk.js"></script>
<script>
  const axn = new AxionSDK({ base: 'https://api.search.axn.cc.cd' });
  const res = await axn.search('kucing', { type: 'web', lang: 'id' });
  const sum = await axn.summary('kucing', { lang: 'id' });
</script>

Node.js

const AxionSDK = require('./axion-search-sdk.js');
const axn = new AxionSDK({ base: 'https://api.search.axn.cc.cd' });
const { results } = await axn.search('cloudflare workers', { safe: true });

External AI agent (OpenAI-compatible tool)

const toolSpec = axn.openaiToolSpec();   // { type:'function', function:{ name:'axion_web_search', ... } }
// Inside your agent's tool-callback:
const data = await axn.aiToolSearch(userQuery);
// -> { query, results:[{title, url, snippet, source}] } — feed back to the LLM.

Methods

  • search(query, {type, safe, lang}) — web / images / videos / news / audio / apps / shop / all.
  • summary(query, {lang}) — grounded AI summary (model auto-selected server-side).
  • chat(messages, {lang, safe}) — AI chat mode with fresh grounding.
  • aiToolSearch(query, {safe, lang}) — compact results for AI agents.
  • health(), searchUrl(query), openaiToolSpec().
